# StudyBuddy

Peer tutoring platform for university students. The repository is a monorepo containing the Flutter client, Node.js API and project documentation.

## Structure

- `api/` — Node.js, Express, TypeScript and MongoDB/Mongoose backend
- `app/` — Flutter mobile application
- `docs/` — design, API and team decisions

## Project status

Initial workspace scaffold. See `docs/backend-architecture.md` and `docs/team-decisions.md` for the agreed starting architecture and scope.
